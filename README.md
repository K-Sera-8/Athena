## Overview
- **Live Deployment:** GitHub Pages
- **Owner:** Phatthanan Siangpro

- `script.js` - Client-side interactions (navigation scroll spy, expandable essay readers, clipboard copy)
- `assets/black.png` - High-resolution logo emblem
- `plan/our_plan.md` - Complete architectural design & deployment plan
